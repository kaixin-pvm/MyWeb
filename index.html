关于 Pvm OS

ABOUT

Pvm OS 是一款基于 TurboWarp 开发的开源伪操作系统， 以“实用、美观、高效、可拓展”为核心，打破传统伪操作系统的功能局限， 兼顾颜值与技术实力，专为热爱系统体验、追求个性化操作的小伙伴打造。 它既是开源技术的实践成果，也是一款可日常体验、可交流学习的轻量化伪操作系统。

核心特点

功能丰富全面

内置桌面设置、主题切换、Pvm AI、计算器、时钟等，兼顾实用与趣味。

UI 精致美观

简约而不简单，配色舒适、图标统一，窗口动画与过渡细腻顺滑。

技术含量突出

基于 TurboWarp 深度优化，模块化架构，代码规范，开源可追溯。

轻量 · 开源 · 共创

占用资源少，适配多场景；MIT 开源，欢迎所有人参与迭代升级。

开发 Pvm OS 的初衷，既是对 TurboWarp 生态的延伸与实践，也是希望打造一款“颜值与实力并存”的开源伪操作系统—— 不追求复杂的功能堆砌，而是在保证技术可靠性的前提下，让系统既好用、又好看， 同时为开源社区提供一个可学习、可交流、可共创的实践项目。

目前 Pvm OS 仍在持续迭代中，后续会根据用户反馈与开源社区的建议，新增更多实用功能、优化 UI 细节、提升运行体验。 也期待每一位热爱开源、喜欢系统体验的小伙伴，一起参与进来，见证 Pvm OS 的成长与进步。
